## 摘要

实现基于 `go-playground/validator` `validate:"..."` struct tag 的静态校验代码生成器：
`k8s.io/gengo/v2` 解析类型与 tag，生成无反射、可审查的 `Validate()` 与 `FillDefaults()`，
提供公共错误模型（`FieldError`/`CollectFieldErrors`）与 runtime adapter（validator/v10），
附 HTTP/gRPC 示例、静态/runtime 一致性测试与文档。

## 变更清单（已实现）

- `cmd/valgen`：CLI，支持多个 `-type` 与 `-output`，gengo 加载 package，gofmt 后原子写入。
- `pkg/ir`、`pkg/parser`：规则 IR、tag 解析、类型检查与规则约束
  （重复规则/required+omitempty/json:"-"+validate/未知或 runtime-only 规则/参数非法与溢出/类型不兼容均生成期报错）。
- `pkg/errorx`、`pkg/check`：`FieldError`/`CollectFieldErrors` 与纯校验 helper
  （email 正则与 validator/v10 一致、UTF-8 长度、oneof）。
- `pkg/gen`：Validate/FillDefaults 生成（稳定顺序、无反射、仅依赖 errorx/check/errors）。
- `pkg/runtime`：validator/v10 StructCtx adapter，支持自定义 validator、dive、跨字段规则，JSON 字段路径映射。
- `example/dto`（含 go:generate 与静态/runtime 一致性测试）、`example/http`、`example/grpc`。
- `README.md`：规则白名单、语义要点、runtime 用法与验收。

## 实现决策

- 与 validator/v10 一致：**同一字段只报告 tag 顺序中第一个失败的规则**（含 required 短路、
  nil 指针短路），因此静态/runtime 对照测试可逐字段逐 code 精确相等。
- pointer 的 `omitempty` 只在 nil 时短路；非 nil 指针（即使指向零值）执行后续规则。
- string 长度按 UTF-8 字符数；数值参数按 validator 规则（base 0）解析后规范化为十进制字面量。
