# validation-gen

基于 `go-playground/validator` `validate:"..."` struct tag 的 Go 静态校验代码生成器。

- 规则声明统一使用 validator 的 `validate:"..."` struct tag，默认值使用 `default:"..."`；
- 使用 `k8s.io/gengo/v2` 解析类型与字段 tag（参考 Kubernetes validation-gen 的架构，
  但不引入其本体、不耦合 k8s API 语义）；
- 生成**无反射、可审查**的 `Validate() error` 与 `FillDefaults()`；
- 静态暂不支持的规则**在生成期报错**，不静默忽略；完整 validator 能力由显式 runtime API 提供；
- 静态语义与固定版本 `go-playground/validator/v10`（v10.30.1）保持一致，
  通过静态/runtime 对照测试验证。

## 快速开始

在目标 package 目录下运行：

```bash
go run github.com/formal-you/validation-gen/cmd/valgen \
  -type=CreateUserRequest -type=Order \
  -output=zz_generated.validation.go
```

或在 DTO 文件中声明 `//go:generate`：

```go
//go:generate go run ../../cmd/valgen -type=CreateUserRequest -type=Order
```

然后执行 `go generate ./...`。生成文件头包含 `Code generated by valgen; DO NOT EDIT.`，
多次生成结果稳定（无 diff），生成失败时不会覆盖已有生成文件。

## 规则声明

```go
type CreateUserRequest struct {
    Name  string  `json:"name" validate:"required,min=3"`
    Email *string `json:"email,omitempty" validate:"omitempty,email"`
    Age   int     `json:"age,omitempty" validate:"gte=0,lte=150"`
    Role  string  `json:"role,omitempty" validate:"oneof=admin user"`
}

type UserRequest struct {
    Role string `json:"role,omitempty" validate:"required" default:"guest"`
}
```

生成：

```go
func (x *CreateUserRequest) Validate() error
func (x *UserRequest) FillDefaults()
```

- `Validate()` 不修改接收对象，不调用 `FillDefaults()`；
- `FillDefaults()` 只填充零值字段，幂等，不覆盖非零值；
- 未加 `validate` tag 的字段一律忽略。

## 静态规则白名单（v1）

| 规则 | 适用类型 | 语义（与 validator/v10 一致） |
| --- | --- | --- |
| `required` | 全部标量 | 零值（指针为 nil）失败 |
| `omitempty` | 全部标量 | 零值（指针为 nil）时跳过剩余规则 |
| `min=N` / `gte=N` | string / 数值 | string 按 UTF-8 字符数 `>= N`；数值按值 `>= N` |
| `max=N` / `lte=N` | string / 数值 | string 按字符数 `<= N`；数值按值 `<= N` |
| `gt=N` / `lt=N` | string / 数值 | 严格大于 / 严格小于 |
| `len=N` | string / 数值 | string 字符数 `== N`；数值值 `== N` |
| `oneof=A B C` | string / 整数 | 必须是候选项之一（整数按十进制字符串比较） |
| `email` | string | 与 validator 的 email 规则一致（需通过 net/mail 解析与正则） |

仅支持标量类型：string、bool、有符号/无符号整数、浮点数，以及它们的 named type 与一级指针。
嵌套 struct、slice/map/array、跨字段与 `dive` 等静态暂不支持，声明即生成期报错。

### 以下规则仅支持 runtime 模式

`required_if`、`required_unless`、`required_with`、`required_without`、`eqfield`、`nefield`、
`gtfield`、`gtefield`、`ltfield`、`ltefield`、`dive`、`keys`、`endkeys`、自定义 validator、
struct-level validator，以及依赖数据库/外部服务的规则。静态生成遇到会明确报错。

## 语义要点

- **同一字段只报告第一个失败的规则**（按 tag 声明顺序），与 validator/v10 一致；
  `required` 失败自然短路该字段其余规则。
- **string 长度按 UTF-8 字符数**，不是字节数（`你好` 计 2 个字符）。
- **pointer**：`nil` 表示未提供；`omitempty` 只在 `nil` 时跳过；
  非 nil 指针（即使指向零值）会执行后续规则。例如 `*string` + `omitempty,min=3`：
  `nil` -> 跳过；`ptr("")` -> 执行 min 并失败；`ptr("a")` -> 执行 min 并失败。
- 无 `omitempty`/`required` 的指针为 `nil` 时，报告 tag 中第一条规则的失败
  （与 validator 对 nil 指针的短路行为一致）。
- **`json:",omitempty"` 只影响 JSON 序列化，不参与校验语义**；optional 语义由
  `validate:"omitempty"` 或指针表达。
- **生成期报错**（不静默忽略）：空 validate tag、未知规则、runtime-only 规则、重复规则、
  `required + omitempty` 冲突、`json:"-"` + validate 冲突、参数非法/溢出、
  类型不兼容（如 bool + min、email + int）、default 非法/溢出、default 用于指针。
- 数值参数按 validator 的解析规则（支持 `0x`/`0o`/`0b` 前缀）解析后规范化为十进制字面量。

## 错误模型

```go
type FieldError struct {
    Field string `json:"field"` // JSON 字段路径，如 "name"、"profile.email"、"items[0].sku"
    Code  string `json:"code"`  // 失败规则名，如 "required"、"min"
}

func CollectFieldErrors(err error) []FieldError
```

`Validate()` 使用 `errors.Join` 聚合所有字段错误，字段顺序与 struct 声明顺序一致。
错误字符串仅用于日志和调试，不作为 HTTP/gRPC 协议。

## Runtime 校验（完整能力）

```go
import "github.com/formal-you/validation-gen/pkg/runtime"

err := runtime.Validate(ctx, v, &req) // v 可传自定义 *validator.Validate；nil 时创建一次性实例
fields := valerr.CollectFieldErrors(err)
```

- 支持自定义规则、alias、`dive`、跨字段规则与 `StructCtx`；
- 不使用全局可变 validator，不修改调用方传入的实例配置；
- 校验错误统一转换为 `FieldError`，字段路径映射为 JSON 名称。

静态与 runtime 模式不在同一个 `Validate()` 中重复执行，避免重复错误与语义不一致。

## 示例

- `example/dto`：DTO 声明、`go:generate`、生成文件、静态/runtime 一致性测试；
- `example/http`：`JSON bind -> FillDefaults -> Validate -> 400 结构化错误`（标准库 net/http）；
- `example/grpc`：`request -> Validate -> status.Error(codes.InvalidArgument, ...)` 与 unary 拦截器。

## 目录结构

```text
cmd/valgen/       CLI（-type 可重复，-output 默认 zz_generated.validation.go）
pkg/ir/          规则 IR
pkg/parser/      tag 解析、类型检查、规则约束
pkg/valerr/      公共错误模型（FieldError / CollectFieldErrors）
pkg/check/       纯校验 helper（email、UTF-8 长度、oneof）
pkg/gen/         代码生成与原子写入
pkg/runtime/     runtime adapter（validator/v10）
example/         DTO / HTTP / gRPC 示例
docs/            spec / issue / goal / pr
```
