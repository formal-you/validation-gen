# Goal 001：静态校验代码生成器（gengo + validate tag）

- 状态：in progress
- 创建：2026-08-22

## 目标

为 HTTP/gRPC request DTO 提供一套参数校验方案：

```text
规则声明统一
静态函数可读
无反射执行
生成结果可审查
runtime 能力可扩展
```

## 范围

- 输入：`validate:"..."` struct tag（canonical source）与 `default:"..."`。
- 输出：`Validate() error`、`FillDefaults()`、`FieldError`/`CollectFieldErrors`、runtime adapter。
- 架构参考：Kubernetes validation-gen 的 validator 注册表/规则 IR/生成器/测试组织方式，
  但不引入其本体，不耦合 k8s API 语义。

## 完成定义（DoD）

1. `cmd/valgen` CLI 可对目标 package 生成稳定、无反射的代码，多次生成无 diff。
2. 11 条静态规则与固定版本 `validator/v10` 语义一致（经静态/runtime 对照测试验证）。
3. 不支持规则生成期报错；非法组合（`required+omitempty`、`json:"-"`+validate 等）生成期报错。
4. 公共错误模型与 runtime adapter 有独立测试覆盖。
5. HTTP/gRPC 示例通过；README 与 tag 行为一致。
6. 本地 gitOps 闭环：issue 001 → PR 001 合并，验收门槛全绿。

## 拆解

- Issue 1：Tag parser 与规则 IR
- Issue 2：Static validation backend（注册表 + Validate 生成）
- Issue 3：Defaults 与公共错误包
- Issue 4：Runtime validator adapter
- Issue 5：HTTP/gRPC 示例与文档
