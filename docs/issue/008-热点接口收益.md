# Issue 008：README 性能对比补充热点接口收益分析

- 状态：open
- GitHub Issue：[#9](https://github.com/formal-you/validation-gen/issues/9)
- 创建：2026-08-23

## 背景

性能对比章节有基准结果，但缺少对「热点接口收益」的量化解读。需要用仓库自己的基准数字
说明：即使生产环境复用 validator 预热实例，热点 URL 上每请求仍可省约 0.8–1.3µs 且分配更少；
这也解释了 codegen 校验为何以「框架无关独立生成器」形态存在，而不是提给 gin/go-zero 内置。

## 需求

1. README「⚡ 性能对比」章节新增小节「热点接口：收益值得关注」：
   - 用 ValidatorWarm 对比给出每请求节省（合法 ~797ns、非法 ~1.3µs 且 allocs 17→29）；
   - 按 RPS 换算单核 CPU 收益（10k RPS ≈0.8% 单核、100k RPS ≈8% 单核）；
   - 说明热点团队直接采用独立生成器（gin 手动调用、go-zero 的 `Validate() error` 接口自动调用）。

## 验收
