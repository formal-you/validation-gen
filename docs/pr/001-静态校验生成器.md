## 摘要

实现基于 `go-playground/validator` `validate:"..."` struct tag 的静态校验代码生成器：
`k8s.io/gengo/v2` 解析类型与 tag，生成无反射、可审查的 `Validate()` 与 `FillDefaults()`，
提供公共错误模型（`FieldError`/`CollectFieldErrors`）与 runtime adapter（validator/v10），
附 HTTP/gRPC 示例、静态/runtime 一致性测试与文档。

## 变更清单（计划）

- `cmd/valgen`：CLI，支持多个 `-type` 与 `-output`，gofmt 后原子写入。
- `pkg/ir`、`pkg/parser`：规则 IR、tag 解析、类型检查与规则约束。
- `pkg/valerr`、`pkg/check`：公共错误模型与纯校验 helper。
- `pkg/gen`：Validate/FillDefaults 生成（stable order、无反射）。
- `pkg/runtime`：validator/v10 StructCtx adapter + JSON 字段名映射。
- `example/dto`、`example/http`、`example/grpc`：示例与集成测试。
- `README.md`：规则白名单、runtime-only 规则、生成与扩展方式。
