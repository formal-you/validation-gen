# Issue 005：分支命名规范（写入 CI 校验）与 AGENTS.md 工作流跳转

- 状态：open
- GitHub Issue：[#3](https://github.com/formal-you/validation-gen/issues/3)
- 创建：2026-08-22

## 背景

main 已线性化，gitOps 工作流已形成（GitHub Issue/PR 为远程权威记录）。
但分支命名规范尚未显式定义并强制：需要把 `<type>/<NNN>-<slug>` 规范写入
docs/gitops/README.md 与 AGENTS.md，并在 GitHub Actions 中校验 PR 分支名。
另外 AGENTS.md 需要能直接跳转查看开发工作流文档。

## 需求

1. 在 `docs/gitops/README.md` 定义分支命名规范：`<type>/<NNN>-<kebab-slug>`，
   type ∈ `feat`/`fix`/`refactor`/`docs`/`test`/`chore`，NNN 为 issue 编号；
2. 在 `.github/workflows/ci.yml` 新增 `branch-name` 作业，PR 时校验分支名符合规范；
3. `AGENTS.md` 顶部增加开发工作流文档（`docs/gitops/README.md`）的跳转链接，
   并在文档流（gitOps）约定中写入分支命名规范；
4. 同步 `CONTRIBUTING.md` 与 `CHANGELOG.md`。

## 验收

- [ ] `docs/gitops/README.md` 含分支命名规范；
- [ ] CI 的 `branch-name` 作业校验分支名，且本 PR 分支名通过；
- [ ] `AGENTS.md` 可点击跳转到 `docs/gitops/README.md`；
- [ ] 本变更通过 GitHub Issue #3 + PR（rebase 合并，main 保持线性）。
